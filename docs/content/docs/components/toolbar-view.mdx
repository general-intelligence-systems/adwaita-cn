## Props

| Prop | Type | From |
| --- | --- | --- |
| `bottomBarStyle` | `flat` \| `raised` \| `raised-border` | Adw.ToolbarView |
| `content` | `node` | Adw.ToolbarView |
| `extendContentToBottomEdge` | `boolean` | Adw.ToolbarView |
| `extendContentToTopEdge` | `boolean` | Adw.ToolbarView |
| `revealBottomBars` | `boolean` | Adw.ToolbarView |
| `revealTopBars` | `boolean` | Adw.ToolbarView |
| `topBarStyle` | `flat` \| `raised` \| `raised-border` | Adw.ToolbarView |
## Variants

### .inline

Removes the styling which makes the widget look part of a header bar.

<Example id="toolbar-view/undershoot-start" />
