## Variants

### .app-notification

OSD appearance with round bottom corners, for an in-app notification.

Deprecated. Use ToastOverlay instead.

### .card

A card: rounded corners and a shadow.

### .linked

Makes a box's children appear as a single group. The box must have no spacing.
