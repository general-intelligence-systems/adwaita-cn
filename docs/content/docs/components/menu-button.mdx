## Variants

### .circular

Round, for a button holding an icon or one or two characters.

<Example id="menu-button/circular" />
### .destructive-action

Uses destructive colours, to warn of damaging consequences.

<Example id="menu-button/destructive-action" />
### .flat

Looks like a label or an icon until hovered.

<Example id="menu-button/flat" />
### .opaque

An opaque background, to be combined with custom background and foreground colours.

Deprecated. Use `.suggested-action` instead.

<Example id="menu-button/opaque" />
### .raised

The regular appearance instead of the flat one, inside a toolbar.

<Example id="menu-button/raised" />
### .suggested-action

Uses accent colours, for the affirmative button in a dialog.

<Example id="menu-button/suggested-action" />
